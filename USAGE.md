# USAGE

## Modules

The idea is separating each part of the code in _modules_ (not the actual c++20 modules).
The `src/` directory will contain a `main.cpp`, being the entry point of the program, and
serie of directories, each containing one or more headers, source files, and a `CMakeLists.txt`
containing the instruction for building a STATIC library.

The structure would be something like this:

- src/
- main.cpp
- foo/
  - foo.hpp
  - foo.cpp
  - CMakeLists.txt

There is an example of this in the initial [src](./src/).

In the root CMakeLists.txt, create the neccesary `add_subdirectory()` functions, and link the
static libraries to the executable.

## compile_commands.json

For clangd correctly working, it is necessary to copy (or better symlink)
the `compile_commands.json` generated by CMake to the root of the project.
